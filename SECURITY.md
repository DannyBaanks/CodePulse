# Security Policy

## Reporting a Vulnerability

Do not report suspected vulnerabilities in public issues.

Use [GitHub private vulnerability reporting](https://github.com/DannyBaanks/CodePulse/security/advisories/new) to send a report directly to the maintainers. Include a clear reproduction, affected files or versions, and the security impact.

## Scope

CodePulse analyzes Python source statically. Findings are heuristics and must be reviewed before acting on them.
